# Contributing

## Adding an engine

The full workflow is documented in [docs/converting.md](docs/converting.md).
The short version:

1. **Export** — write `conversion/export_<engine>.py` following the contract
   in `docs/converting.md#1-export`. Use `conversion.export_base` helpers for
   opset 14, dynamic axes, manifest, and provenance.

2. **Parity check** — run `python -m conversion.parity` and confirm tolerances
   pass (max_abs ≤ 1e-3, mean_abs ≤ 1e-4 by default). Export fails on parity
   violation.

3. **Quantize** — run `python -m conversion.quantize` to produce `*_q8.onnx`
   INT8 variants.

4. **Push to HF** — run `python -m conversion.push_models` after dry-run
   verification. Models go to `TigreGotico/voiceclonnx-<engine>`.

5. **Write the adapter** — subclass `VoiceClonerBase`, implement `clone_voice`,
   call `register_engine`. See [docs/api.md](docs/api.md#adding-a-custom-engine).

6. **Register** — add the auto-import to `voiceclonnx/__init__.py`.

7. **Add engine doc** — create `docs/engines/<engine>.md` using the template
   in any existing engine doc (Overview, How it works, Config/params, Model and
   license, Sample rate, INT8 note, WER, CLI example, Python example,
   Troubleshooting, References).

8. **Update engine table** — add a row in `README.md` and `docs/index.md`.

## Demo and verification gate

Every engine must pass the demo/verify gate before merging:

```bash
# Generate demo clips for the new engine
python demo/generate_demos.py --engines <engine>

# Verify WER (gate: WER ≤ 40%)
python demo/verify_demos.py
```

Commit the generated `.wav` output files in `demo/outputs/` and the updated
`demo/VERIFICATION.md`. The verification file is generated by `verify_demos.py`
— do not hand-edit it.

## Running tests

```bash
pip install -e ".[test]"
pytest tests/ -x
```

Tests are organized one file per engine (`tests/test_<engine>.py`) plus shared
tests (`test_registry.py`, `test_cloner.py`, `test_cli.py`, etc.).

New engines should include at minimum:
- A smoke test that instantiates the adapter and calls `clone_voice` on a short
  synthetic clip.
- A registry test confirming the alias is present in `ENGINE_REGISTRY`.

## Quantization note

If your engine does not support INT8 (e.g. the upstream repo provides no INT8
variants), set `quantized=True` to be silently ignored in the adapter and
document this in the engine guide and `docs/QUANTS.md`.

## Code style

Line length: 120 (`ruff` enforced). Python 3.9+. No torch, no librosa in
adapter code — inference-time dependencies are `onnxruntime`, `numpy`,
`soundfile`, `huggingface_hub` only.

## Weight-license policy

Read [docs/converting.md](docs/converting.md) for the distributable vs
local-only classification. Do not push weights to HF if the upstream license
does not permit redistribution — the export script enforces this via
`write_manifest(..., distributable=False)` / `push_models` refusal.

## Commit style

Conventional commits (`feat:`, `fix:`, `chore:`, `docs:`). Versions bump
automatically from commit prefixes — do not edit `voiceclonnx/version.py`.
